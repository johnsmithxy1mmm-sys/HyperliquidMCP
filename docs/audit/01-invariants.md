# Фаза 1 — Инварианты

Статус проверки: **К** — проверяется в коде · **Т** — есть тест · **—** — не проверяется нигде.
Инвариант со статусом «—» уже является находкой (`INV-*`).

## Деньги и биллинг

| # | Инвариант | К | Т | Статус |

| M2 | payment_id уникален для разных платежей (нет коллизий) | ✓ | — | sha256 всего payload, теста нет |
